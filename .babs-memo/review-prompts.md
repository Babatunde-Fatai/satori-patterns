# Review Prompts (use for medium or large changes)

## Self-review checklist

Return:

RISK
LOW | MEDIUM | HIGH

MUST FIX
- …

SHOULD FIX
- …

BREAKING CHANGES
- none OR list

SECURITY
- role checks, auth flows, token handling, input validation

UX
- loading, errors, empty states, a11y

PERFORMANCE
- obvious footguns, unnecessary re-renders, large bundles

VERIFICATION TO RUN
- exact commands or manual steps
