# .babs-memo

This folder is the contract between you and coding agents.

Why it exists:
- Work spans weeks.
- Agents forget.
- You need durable memory plus a live task board.

Structure:
- sessions/ = daily session logs with explicit TASK BOARD and WORK LOG
- memory/ = per-project durable decisions
- MEMORY_INDEX.md = index only
- TASK_RULES.md = rules and review triggers
- PROMPT_STARTERS.md = copy/paste openers

How you use it:
1) Start prompts using PROMPT_STARTERS.md Default.
2) Agent must output STATE RECEIPT then TASK BREAKDOWN.
3) Session file is updated as work happens.
4) Durable decisions go into memory/<project>.md.
