# Curated Color Palettes

Each palette includes 5 roles: Background (dominant), Accent (primary), Surface (secondary), Warmth (tertiary), and Text.

WCAG note: contrast below is calculated between `Text Primary` and `Background` using the WCAG relative luminance formula `((L1 + 0.05) / (L2 + 0.05))`. AA target for normal text is `>= 4.5:1`.

## Contrast Audit Summary

All existing 10 palettes pass AA for `Text Primary` on `Background`. No correction is required for those pairs.

## Failures and Corrections

- No palette currently fails the AA 4.5:1 threshold for `Text Primary` on `Background`.
- Corrected hex recommendations are not required at this time.

## Usage Notes

When combining palette elements across two palettes, always maintain:
1. One dominant background (around 80% of the page surface)
2. One accent used sparingly (buttons, hover states, key typographic marks)
3. Consistent text hierarchy (primary text, muted text)
4. A maximum of one light-break section per page if using a dark palette

Never use more than 6 colors in a single design system.
